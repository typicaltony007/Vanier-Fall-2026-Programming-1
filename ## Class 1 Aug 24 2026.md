## Class 1 Aug 24 2026
- Smallest unit in computer memory is a **bit(b)**, which can only be 0 or 1
- By grouping 8 bits, we get a **byte(B)**
- 1KB = 1024B, while 1024 is 2 ^ 10

- JRE stands for Java Runtime Environment
- JVM stands for Java Virtual Machine (for only running Java)
- JDK stands for Java Developer Kit (for dev)

- LTS stands for Long-Term Support
- Current LTS version is 25

- Source code: The code dev write
- Binary/Machine code: The code computer understand (0 and 1)
- Compiling: Bring high-level code to low level code
- Byte code: Java invents, close to machine code
- Java compiling: Source code -> Byte code

- VCS stands for Version Control System (related to Git)
