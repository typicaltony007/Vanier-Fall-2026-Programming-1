## 1. Equipment

### 1.1 Computer

You do not need your own computer for this course because the lab machines already include everything you need. However, having a personal laptop or desktop can make studying and completing assignments more convenient. Windows, macOS, and Linux are all suitable, although Windows may be the easiest option because it is used on the lab computers and the keyboard shortcuts will match.

If you are buying a new computer, there are no strict requirements; any modern machine should be sufficient. For a laptop, consider choosing one with:

- An English keyboard, which is commonly used in workplaces.
- Full-sized arrow keys, which are useful when coding.
- Dedicated `Home`, `End`, and `Delete` keys rather than shared keys.

### 1.2 Storage

You do not need a flash drive. Instead, save your work in the cloud. The college provides you with a free `Office 365` account, including `OneDrive`, where you can store your files securely.

## 2. Typing Speed

Regardless of your career path, typing quickly and accurately will save you time.

- Aim for a minimum of `40` words per minute (WPM).
- Work toward a speed of `60` WPM or higher.
- Learn touch typing: typing without looking at the keyboard.

For practice:
- If you already know how to touch type, try [Monkeytype](https://monkeytype.com/). Practicing for 15 minutes a day can produce noticeable results within two weeks.
- If you are new to touch typing, try [TypingClub](https://www.typingclub.com/). Begin slowly and gradually increase your speed.

## 3. Use the Keyboard

Relying on the mouse can slow you down. Train yourself to use keyboard shortcuts whenever possible; they are faster and will make you more efficient.

## 4. Ask Questions Effectively

When asking for help, be specific. Instead of simply saying, “It does not work,” provide enough information for someone else to understand and reproduce the problem:

- Describe what is going wrong.
- Explain what you have already tried.
- Include relevant details, such as error messages and the steps you followed.

Clear questions = faster, better answers.

## 5. Review Often

Even if something seems easy, you may forget it quickly without a regular review.

- Review the material on the same day you learn it.
- Remember that taking notes is not enough; reviewing is what helps knowledge stick.

## 6. Practice Until It’s Automatic

If it takes you more than five minutes to write a solution you have already seen, keep practicing. Repeat the task until you can complete it smoothly in less than five minutes. At that point, you can consider the skill mastered.

## 7. Schedule Everything

In college, no one will remind you to study, so self-discipline is essential. Success usually comes from developing good habits, not from intelligence alone.

- Create a daily or weekly schedule.
- Follow it consistently.
- Use it to avoid missed deadlines and last-minute stress.

## 8. Markdown

I use Markdown (`.md`) to write the lectures because it is lightweight, simple, and free. You can open Markdown files in almost any text editor and in many browser-based applications.

Learn the basics of:
- Headings
- Bold / Italic
- Ordered and unordered lists
- Inline code and fenced code blocks

Resources:
- [Markdown Guide](https://www.markdownguide.org/)
- [Markdown Cheat Sheet](https://www.markdownguide.org/cheat-sheet/)
- YouTube tutorials; search for `Markdown`.

## 10. Useful Keys

| Key      | Usage                                                        |
| -------- |--------------------------------------------------------------|
| `Home`   | Move cursor to beginning of line                             |
| `End`    | Move cursor to end of line                                   |
| `Delete` | Delete character after cursor                                |
| `Insert` | Toggle between `insert` and `overwrite` mode                 |
| `Tab`    | Indent code / autocomplete / move to next option in a wizard |

## 11. Typing Tricks

1. Double-click a word → select it.
2. Triple-click → select an entire line.
3. `Ctrl` + `left`/`right`: jump one word
4. `Ctrl` + `Backspace`: delete the word before the cursor.
5. `Ctrl` + `Delete`: delete the word after the cursor.
6. `Shift` + `←`/`→`: select one character.
7. `Ctrl` + `Shift` + `←`/`→`: select one word.
8. `Home` + `Shift` + `End` (or vice versa): select a whole line.
