## Class 2 Aug 26 2026

- **Camel case**: xxXxxxxXxxxXxxxx, XxXxxxxXxxxXxxxx (Java)
- **Snake case**: xx_xxxxx_xxxxx (Python)
- **Kebab case**: xxx-xxx-xxx

- A project name must start with **uppercase**, e.g. HelloWorld, SchoolGradingSystem

- `pom.xml` is a file related to **maven** build system
- `src` stands for source, where is the place devs write source code
    - `main`: The Java source code
        - `Main.java` is a Java source code file
    - `test`: For unit testing


- All comments will be ignored during the compiling
- `//` is a single line comment
- `/* thing */` is a multi-line comment
- `class` is the biggest set
